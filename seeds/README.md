# Seed Library

`promptmap_adapted.json` contains starter seeds for authorized Agent prompt-injection testing.

## Provenance

The initial strategy families were reviewed from PromptMap:

- Repository: https://github.com/utkusen/promptmap
- License: GPL-3.0

The templates in this directory are rewritten for agentOwl and use the generic `{{attack_goal}}` placeholder. They are not verbatim copies of PromptMap prompts. Each seed records `source_repo`, `source_path`, `adapted_from`, and `provenance` metadata so test results can be traced back to the strategy that inspired the seed.

Do not remove provenance metadata when adding mutations derived from these seeds; preserve or extend it when practical.
